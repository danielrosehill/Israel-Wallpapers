# Israel Wallpapers

A collection of wallpaper images showcasing various scenes from Israel.

## About

This repository contains images of Israel in various formats and orientations. All images were taken by me, Daniel Rosehill.

These images are also available on Pexels: https://www.pexels.com/@danielrosehill/collections/

## Installation

Run the interactive installation script to install the wallpapers to your system:

```bash
./install.sh
```

The installation script allows you to:
- Choose the installation directory (default: `~/wallpapers`)
- Preserve folder structure or use a flat layout
- Filter by orientation (all, portrait 9:16, or landscape 16:9)
